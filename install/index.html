Warren Buffett Brain is a research library and Buffett-inspired analysis workflow, not an official Buffett chatbot. It offers 55 original evidence notes, eight case studies and 60 links to historical sources. You do not need a Buffett Brain account or a subscription to read the research.

1. Try the research prompt in ChatGPT

Open ChatGPT, copy this prompt, and replace the ticker. This works now as an ordinary prompt, without installing a plugin.

Analyze [COMPANY / TICKER] using Buffett-inspired principles. Explain how the business makes money, evidence for and against a durable moat, management's capital allocation, owner-like cash flow, debt and the biggest risk. Separate company quality from the price I would pay. Use dated primary filings, distinguish facts from assumptions, challenge the thesis and cite sources. Never invent prices or Buffett quotes.

What happens: ChatGPT uses whichever sources and tools are available in your conversation. Pasting the prompt does not automatically load the historical archive on GitHub or install the Buffett Brain Skill.

2. Import the historical research as a Skill (eligible workspaces)

Some ChatGPT Business, Enterprise, Healthcare and Edu workspaces can upload Personal Skills, depending on settings and permissions. If your ChatGPT account shows Plugins → Skills → Create → Upload from your computer:

  1. Download the Personal Skill ZIP.
  2. Upload it to the Skills uploader and follow the review prompts.
  3. Ask: “Use Warren Buffett Brain to explain Berkshire's GEICO investment and cite the historical evidence.”

Check the official ChatGPT Skills eligibility and setup guide. This is a bundled research Skill, not a live stock-data connection.

3. Public plugin availability

The repository also provides a Skills-only plugin ZIP. Warren Buffett Brain is not yet publicly listed in the ChatGPT Plugins Directory. That ZIP is a different format from the Personal Skill ZIP and should not be uploaded to the Personal Skills uploader. A public install link will be provided only if an actual listing is approved and available.

4. AI agents and optional desktop MCP

Agents with access to the repository can follow AGENTS.md to read the actual evidence index and case studies. Do not claim the source material was loaded if you only pasted a prompt.

Advanced users with a compatible local stdio MCP desktop client can run the Python MCP adapter and use the read-only search, fetch and research_overview tools. This is not a one-click ChatGPT web/mobile connector.

Research quality and limitations

Buffett Brain links to original publishers but does not contain full copyrighted books, letters or transcripts. Historical notes are independent summaries and interpretations. For a modern stock, independently verify current corporate filings, share price, valuation inputs and risks. The project cannot trade, read private portfolios, or provide a Buffett-endorsed stock pick.

Independent project, not affiliated with Warren Buffett or Berkshire Hathaway. An optional ValuEdge valuation platform is operated by the same maintainer; it is a separate commercial product and not needed to use this open-source research.
