Bring the evidence into your investment research.

The Buffett Brain skill packages 55 original evidence notes, 60 original-source links, and eight research case studies. The skill needs no dedicated server, broker login, or ValuEdge account. ChatGPT itself requires an internet connection.

ChatGPT Plugin

The Skills-only ZIP is ready for author submission or compatible local plugin sources. Public Plugins Directory installation is not yet available: OpenAI must review and approve the release before strangers can install it directly in ChatGPT.

Try the research approach today

In ChatGPT, try: “Research GEICO as Warren Buffett did, distinguishing the original evidence, the moat and the strongest counterargument. Cite primary sources.” A copied prompt does not automatically install the skill.

Local MCP for desktop clients

For compatible desktop MCP clients, the no-hosting Python MCP reads the same public research corpus locally. It runs on the user’s machine with no always-on cloud service. This is not a ChatGPT web connector.
