POLICY · UPDATED 4 NOVEMBER 2026

Privacy and data handling.

Warren Buffett Brain is an independent open-source research project. It does not require an account, financial credentials or broker connections for its bundled historical research.

Research and prompts

The source-linked data set is bundled in the Skills-only package. The project operates no hosted backend to receive ChatGPT prompts. ChatGPT requests are processed by your AI provider under its own privacy settings and policies.

Local MCP

The optional desktop MCP adapter reads publicly committed research notes on your own device and does not make network requests or store your search terms in a remote database.

Website and third parties

The public research website is hosted on GitHub Pages. GitHub may collect normal server access records. Following cited primary-source links takes you to external publishers with their own privacy practices.

Optional ValuEdge connection

ValuEdge is a separate product. This skill does not connect to it automatically. Any optional use requires the user to choose that integration independently, subject to the provider’s own privacy policy.

Support

Public issues can be reported at GitHub Issues; do not include private account data in a public issue.
